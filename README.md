# 🐾 ResQPet – Java-Based Animal Rescue Web Application

**ResQPet** is a web application built in Java to enable users to report stray or injured animals and notify nearby NGOs for quick rescue action. It offers a real-time dashboard for NGOs to manage reports and an admin interface to oversee operations.

---

## 🌟 Features

- 📍 **Submit Rescue Requests** with location, image, and description  
- 🏥 **NGO Dashboard** to view and update assigned reports  
- 🛠️ **Admin Panel** to monitor and assign cases  
- 📸 **Image Upload** support for better reporting

---

## 🛠️ Tech Stack

| Layer          | Technology Used            |
|----------------|----------------------------|
| Frontend       | HTML, CSS, JSP, JavaScript |
| Backend        | Java Servlets (JSP + JDBC) |
| Database       | MySQL                      |
| Image Handling | Servlet Multipart API      |
| Build Tool     | Pure Java (No Maven)       |
